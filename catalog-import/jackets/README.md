# Jaquetas — Minkang

Fonte: https://minkang.x.yupoo.com/categories/4093293

376 modelos, 74 equipes, 3.099 fotos. Dos 401 álbuns anunciados, 391 tinham link público; 10 indisponíveis foram registrados em unavailable.json. Foram excluídos 14 itens sem equipe ou tabelas de medidas e uma duplicação exata de capa/equipe. Comparação de IDs/álbuns com todos os imports anteriores, inclusive arquivos .json.gz, não encontrou itens já cadastrados.

A categoria do fornecedor reúne jaquetas, corta-ventos, moletons e blusas de treino. Os nomes em português distinguem esses tipos; todos aparecem no filtro Jaquetas. As 391 capas públicas foram conferidas em folhas de contato, com ampliação de 16 casos e revisão das galerias de duas peças cuja capa estava de costas. As jaquetas Bayern e Club America passaram a abrir de frente. Uma variante Espanha com título vermelho mas foto branca foi corrigida para branco e vermelho. Variantes com títulos iguais foram preservadas quando as fotos diferem.

As galerias completas ficam nos lotes JSON compactados, sem perdas. Preparar SQL com `node scripts/prepare-nba-import.mjs jackets`. Import aditivo e repetível sem sobrescrever produtos existentes. Fotos usam a origem Minkang já autorizada e são copiadas para R2 quando abertas. Temporadas e versões seguem o fornecedor; disponibilidade, preços e tamanhos são consultados no WhatsApp.
