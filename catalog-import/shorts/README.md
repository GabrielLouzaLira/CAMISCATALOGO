# Shorts de clubes e seleções

Fonte: https://16620059194.x.yupoo.com/categories/4991390

Importação de 128 modelos, 42 equipes e 798 fotos. Os três álbuns de shorts casuais sem equipe foram excluídos conforme pedido do usuário. Nenhum short avulso foi encontrado nos imports existentes; imagens e galerias idênticas são comparadas para evitar repetição. Títulos iguais com cores diferentes foram preservados e diferenciados pelo nome.

As capas dos 131 álbuns foram conferidas visualmente. A foto frontal de capa abre cada galeria, mesmo quando a primeira foto do álbum original é um detalhe ampliado. Galerias permanecem completas. Os modelos Brasil descritos como Basketball pelo fornecedor têm escudo CBF e ficam na seleção brasileira de futebol, identificados como estilo basquete.

Temporadas e versões seguem as informações do fornecedor, sem afirmar autenticidade ou disponibilidade. Tamanhos e preços são consultados pelo WhatsApp.

Fotos são copiadas ao R2 na primeira abertura. Novo fornecedor limitado ao caminho /16620059194/ no host photo.yupoo.com. A coleção usa as equipes existentes; Juventus foi adicionada com escudo ESPN.

Preparar SQL: `node scripts/prepare-nba-import.mjs shorts`. O import é aditivo e não sobrescreve produtos já cadastrados.
